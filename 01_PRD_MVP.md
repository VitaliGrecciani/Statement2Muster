# Product Requirements Document (PRD) — MVP v1.0

**Название проекта:** Statement2Muster (или BankSync)
**Цель:** Автоматическая конвертация банковских выписок (PDF/CSV) в стандартизированный формат (Muster) для импорта в бухгалтерские системы (BMD, DATEV).
**Платформа:** Браузерное расширение (Google Chrome).

## Основной флоу (User Journey)

1. Пользователь кликает на иконку расширения в браузере.
2. Открывается popup-окно с drag-and-drop зоной.
3. Пользователь перетаскивает файл выписки (например, Wise CSV, VR Bank PDF, Amex PDF).
4. Файл отправляется на бэкенд → парсится → маппится в формат Muster.
5. Бэкенд возвращает готовый CSV.
6. Расширение автоматически скачивает файл на Windows машину пользователя.

## Монетизация (MVP)

Без авторизации дается 3 конвертации (хранится в `localStorage`). Далее — редирект на лендинг для покупки подписки через Stripe.
