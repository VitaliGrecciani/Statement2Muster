# Структура монорепозитория

Для удобства управления кодом развернем все в одном репозитории:

```text
statement2muster/
├── extension/             # Исходники Chrome-расширения
│   ├── manifest.json
│   ├── popup.html
│   ├── popup.js
│   ├── background.js      # Service worker для Manifest V3
│   └── styles.css
├── backend/               # FastAPI сервер
│   ├── app/
│   │   ├── main.py        # Точка входа API
│   │   ├── parsers/       # Логика парсинга (wise.py, amex.py, vrbank.py)
│   │   └── core/          # Настройки, CORS, Stripe вебхуки
│   ├── requirements.txt
│   └── Dockerfile
└── web/                   # Next.js лендинг и дашборд
    ├── app/
    ├── components/
    ├── package.json
    └── tailwind.config.js
```
