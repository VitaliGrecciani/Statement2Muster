## Граница совместимости

Принимается показанный Lifetime refund через сохранённый payment_intent. Новая запасная ветвь возврата подписки использует старое PI.invoice либо metadata.subscription_id; вызова Invoice Payment API в ней нет. Поэтому результат Lifetime не объявлять доказательством полного покрытия возвратов подписок в Clover. Это ограничение оценки совместимости, не дополнительный сценарий для закрытия принятой пятисценарной матрицы S05.

Синтетический GO Решения 37, C07 и Managed Extension сохраняются. Полная совместимость всех legacy/new payloads не следует из одного числа 30/30: формулировать результат в пределах реально исполненных сценариев. Общий Full GO для клиентских выписок этим решением не выдаётся.
