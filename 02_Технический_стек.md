# Технический стек и архитектура

Стек подобран под быстрый старт, асинхронную обработку данных и удобный деплой.

## Client (Chrome Extension)

- **Стек:** HTML/CSS/Vanilla JS (или React) + Manifest V3.
- **Задачи:** UI загрузки файла, запрос к API, скачивание ответа.

## Backend (API Engine)

- **Стек:** Python + FastAPI.
- **Инструменты:** `pandas` (для CSV), `PyPDF2` / `pdfplumber` (для PDF), интеграция с Gemini Flash для парсинга сложных неструктурированных кусков (как мы делали с Amex).
- **Деплой:** Docker-контейнер на сервере Hetzner.

## Landing & Auth (Web App)

- **Стек:** Next.js (App Router) + TailwindCSS.
- **База данных:** PostgreSQL (через Supabase или поднятая в Docker) для учета лимитов пользователей.
- **Биллинг:** Stripe Checkout.
- **Деплой:** Vercel.
